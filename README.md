# Caudex Documentation Repository

This repository contain all the documentation related to the Caudex
project.

Documentation is separated into two main category:
 - Caudex Standard Recommendation (Abbreviated CSR)
 - Caudex Standard Proposal (Abbreviated CSP)

Recommandations are documents currenty in use, where proposal are documents
talking about future changes for the language.

The separation is to allow for discussion for changes in the language or the 
compiler and tools, where the recommandations are already agreed aspect of
Caudex.

You will find all CSR documents in the CSR folder, and CSP documents in the 
CSP.

> **Note:** Not all document has been published yet as they are currently being reviewed before first publication.
